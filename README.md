# Worlder 私有 QMS 与自研气泡识别软件

为工业图纸气泡识别服务配套的私有化质量管理系统（QMS），参照云质 QMS 资料和内部 QMS V3 设计。本仓库包括原始资料、需求与开发流程文档、QMS 前端原型，以及一套自研的气泡识别软件。

## 快速开始（QMS + 气泡识别软件一起运行）

需要 Node.js 18 以上和 Chrome / Edge。

```bash
cd 私有QMS交付/04_气泡识别软件
npm install        # 安装 pdf.js、tesseract.js（含离线语言包）和构建工具
node build.mjs     # 构建气泡识别软件
node server.mjs    # 启动服务
```

启动后浏览器会自动打开 QMS。启动服务的终端窗口不要关，关了服务就停了。

- QMS 原型：http://localhost:5180 ，左侧“气泡识别”页面里内嵌了气泡识别软件
- 气泡识别软件单独打开：http://localhost:3080

要用气泡识别，必须通过 http://localhost:5180 打开 QMS。直接双击 `qms_pro_qms.html` 打开的页面（地址栏是 `file://`）不在白名单里，气泡软件嵌不进去、同步结果也收不到，页面上会提示改用正确的地址。只看 QMS、不用气泡识别时，双击打开没有问题。
