# Worlder 私有 QMS 与自研气泡识别软件

这套生产质量管理原型用工单串起来料、首件、巡检、完工检验和出货检验。生产主管报工，检验员录数，质量负责人处理异常并决定放行。图纸标注由配套的气泡识别软件完成。

**[下载工单实操演示包 ZIP](私有QMS交付/03_前端原型/demo/Worlder-QMS-工单实操演示.zip?raw=true)**

解压后用电脑浏览器打开 `开始演示.html`，可离线操作。随包的 `演示讲解卡.html` 可以打印成一页。演示进行到一半时刷新页面，可以在同一标签页继续。

## 用一张工单讲完整个流程

默认打开 `WO-DEMO-208` 的精车巡检。208 件阀芯已经投产，来料和首件检验已有示例报告。右上角可以切换「手机视图」，也可以在「重新演示」中选择「从工单登记开始」。

| 环节 | 操作 | 可以给观众看的结果 |
|---|---|---|
| 巡检与留证 | 在样本 S1 输入 `20.12 mm`，添加示例照片，提交巡检。 | 页面标出读数超过 `20.10 mm` 上限，工单进入异常处置。 |
| 处置与复检 | 演示中复筛确认 8 件不合格。分配返工 5 件、报废 3 件，先只批准报废。 | 返工行仍待批准。分别登记执行凭据、复检合格并关闭不合格单后，工单仍显示限制，直到负责人明确解除。 |
| 报工与出货 | 报工合格 205 件，完成完工检验。第一批交检 100 件，第二批先填 106，再改为 105。 | 第二批显示剩余 105 件，超量时无法开检。两个批次各自保留检验报告。 |
| 整单放行 | 复核两批报告后，质量负责人核对放行条件并确认放行。 | 工单记录显示投入 208 件、合格入库 205 件、报废 3 件，可回看原检和复检报告。 |

## 从源码运行

需要联动图纸气泡识别时，在仓库根目录执行以下命令。开发环境需要 Node.js 18 以上和浏览器。

```bash
cd 私有QMS交付/04_气泡识别软件
npm install
node build.mjs
node server.mjs
```

保持终端运行。在 `http://localhost:5180` 打开 QMS，工程人员从「图纸与标准 → 气泡识别」进入标注工作台。气泡服务也可以在 `http://localhost:3080` 单独打开。

如需重新生成分发包，在 `私有QMS交付/03_前端原型` 中运行 `npm run delivery`，然后用 `npm run test:delivery` 验证解压后的实操流程。[构建与测试说明](私有QMS交付/03_前端原型/README.md)
