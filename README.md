# Worlder 私有 QMS 与自研气泡识别软件

这套生产质量管理原型用工单串起来料、首件、巡检、完工检验和出货检验。生产主管报工，检验员录数，质量负责人处理异常并决定放行。图纸标注由配套的气泡识别软件完成。

**[下载工单实操演示包 ZIP](私有QMS交付/03_前端原型/demo/Worlder-QMS-工单实操演示.zip?raw=true)**

解压后用电脑浏览器打开 `开始演示.html`，可离线操作。随包的 `演示讲解卡.html` 可以打印成一页。演示进行到一半时刷新页面，可以在同一标签页继续。

## 下载后怎么运行

### 1. 取得代码

仓库是私有的，需要先由仓库管理员把你加为协作者。下面两种方式任选一种：

- **用 git 下载**：`git clone https://github.com/Xyvy-57/QMS.git`，会得到 `QMS` 文件夹。
- **下载 ZIP**：在 GitHub 仓库首页点「Code → Download ZIP」，解压后得到 `QMS-main` 文件夹。Windows 自带的解压工具如果把中文文件名解成乱码，改用 7-Zip 解压，或者用 git 下载。

在 GitHub 网页上直接点 HTML 文件只会显示源码，要下载到本机后再用浏览器打开。下文的路径都从这个文件夹算起。

### 2. 只看界面：不用安装任何软件

用 Chrome 或 Edge 打开 `私有QMS交付/03_前端原型/qms_pro_qms.html`，可以切换岗位，走完建单到放行的全部流程。演示数据保存在本机浏览器里，想恢复初始数据，点右上角头像 →「重置演示数据」。

- 想看带实拍画面的操作导览，打开 `私有QMS交付/03_前端原型/demo/工单操作演示.html`。这个文件可以单独拷给别人。
- 这种打开方式下，「气泡识别」页面嵌不进气泡软件；需要联动气泡识别时，按第 3 步启动。

### 3. 完整运行：QMS 联动气泡识别

先安装 [Node.js](https://nodejs.org/zh-cn) 18 或以上版本，选 LTS 版即可。装好后打开终端（Windows 用 PowerShell），执行 `node -v`，能看到版本号就说明装好了。

然后进入下载的文件夹（`QMS` 或 `QMS-main`），依次执行：

```bash
cd 私有QMS交付/04_气泡识别软件
npm install
node build.mjs
node server.mjs
```

- `npm install` 只在第一次需要，会下载约 200 个依赖包（包括图纸识别用的中英文语言包），要联网，通常一两分钟。国内网络慢时改用 `npm install --registry=https://registry.npmmirror.com`。
- `node build.mjs` 也只在第一次、或代码更新后需要。
- 以后每次使用，只需要在这个目录执行 `node server.mjs`。

启动成功后，终端会显示「Worlder 气泡识别服务已启动」，浏览器会自动打开 QMS。没有自动打开时，手动访问 **http://localhost:5180**。终端窗口不要关，关了服务就停了；要停止服务，在终端按 `Ctrl+C`。

工程人员从「图纸与标准 → 气泡识别」进入标注工作台。气泡服务也可以在 `http://localhost:3080` 单独打开。

要让手机或平板访问，改用 `node server.mjs --host 0.0.0.0` 启动，终端会列出局域网地址。

### 4. 常见问题

| 看到的提示 | 原因与处理 |
|---|---|
| `command not found: node`，或「node 不是内部或外部命令」 | 没有安装 Node.js，或者装完没有重新打开终端。 |
| `Cannot find module …/server.mjs` | 当前目录不对。先 `cd` 到 `私有QMS交付/04_气泡识别软件` 再执行。 |
| `端口 3080 启动失败 … EADDRINUSE` | 之前启动的服务还开着，直接访问 http://localhost:5180 即可。要重启：先关掉之前的终端窗口；找不到窗口时，macOS 执行 `lsof -t -i tcp:3080 -i tcp:5180 \| xargs kill`，Windows 执行 `netstat -ano \| findstr :3080`，再用 `taskkill /PID 进程号 /F` 结束查到的进程。 |
| 「气泡识别」页面显示未连接、内容空白 | 双击 HTML 打开时会这样。要用 http://localhost:5180 访问，而且 `node server.mjs` 要在运行。 |
| 页面还是旧的样子 | 服务启动后又更新过代码。刷新浏览器；还不行就重新执行 `node build.mjs`，再重启服务。 |

如需重新生成分发包，在 `私有QMS交付/03_前端原型` 中运行 `npm install`、`npm run delivery`，然后用 `npm run test:delivery` 验证解压后的实操流程。打包需要 `python3`。[构建与测试说明](私有QMS交付/03_前端原型/README.md)
