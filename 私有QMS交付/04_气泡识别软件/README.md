# 自研气泡识别软件（首期原型）

上传工业图纸，自动识别尺寸、公差、形位公差、粗糙度、螺纹和技术要求，摆放气泡，人工校核后冻结，并同步给 QMS。可以私有化部署，识别全部在本机浏览器里完成，不调用任何云服务。设计依据见 [设计说明.md](设计说明.md)。

> **状态（2026-11-17）**：代码已写完，`node build.mjs` 的源码检查（JS 语法、页面模板预编译）已通过；还没有在浏览器里实际运行过，测试待补。

## 运行

```bash
npm install        # pdf.js、tesseract.js 与英文 / 简体中文离线语言包、Tailwind、Vue
node build.mjs     # 复制运行库到 vendor/，检查源码，生成 dist/bubble.html
node server.mjs    # 气泡识别 http://localhost:3080，同时托管 QMS 原型 http://localhost:5180
```

`server.mjs` 只用 Node.js 自带模块。常用参数：`--port`、`--qms-port`（0 表示不托管 QMS）、`--data`（数据目录，默认 `./data`）、`--host`（内网部署用 `0.0.0.0`）。

## 功能

| 页面 | 做什么 |
|---|---|
| 图纸库与标注 | 拖入 PDF / PNG / JPG / SVG → 自动识别 → 确认图纸信息 → 在标注工作台逐项校核 → 冻结并同步 |
| 标注工作台 | 左边图纸：缩放、平移、拖动气泡、框选识别、点击加气泡；右边特性清单与编辑；撤销；导出带气泡 PDF、特性清单 CSV、气泡 JSON、打印检验记录表 |
| 图纸对比 | 两个版本按特性 ID 比较：沿用、变更（标出放宽 / 收紧）、新增、删除；图面并排或叠加 |
| 相似图纸 | 按特性组成和图面相似度查找 |
| 公差标准 | GB/T 1804 一般公差表、ISO 286 配合公差计算、识别规则在线试解析 |
| 设置与对接 | QMS 地址白名单、识别默认值、消息记录、数据导出 |

工序、质检单、检具、报告模板在 QMS 里维护，这里只放跳转入口，避免同一份数据维护两套。

## 识别怎么做

1. **取文字**：CAD 导出的 PDF 用 pdf.js 直接读文字和位置；SVG 用浏览器排版取文字；扫描件和图片用 tesseract.js 本机 OCR，横排、竖排各识别一遍。
2. **拼成标注**：同一方向、同一基线、相邻的文字拼成一条；识别叠放在尺寸右侧的上下偏差；形位公差框格里的符号、公差、基准拼在一起。
3. **分区**：找出标题栏（读取图号、名称、零件号、材料、版本、比例、未注公差）、技术要求、图框分区编号、视图名称。
4. **解析规格**：直径、半径、对称与不对称偏差、极限尺寸、配合代号（ISO 286 查表）、角度、倒角、螺纹、数量、粗糙度、14 种形位公差、硬度等；没写公差的按未注公差等级查 GB/T 1804。所有上下限按十进制精确计算。
5. **摆放气泡**：放在标注旁边，不压文字、不互相重叠，按阅读顺序编号。
6. **换版映射**：新版本按位置、类型、名义值、公差与上一冻结版逐项打分，沿用旧特性 ID；分不清的标“无法确认”，必须人工选定后才能冻结。

## 与 QMS 的对接（PRD §7）

- 浏览器消息：`worlder.ready`、`worlder.balloon.frozen`、`worlder.navigate`；接收 `qms.context`、`qms.navigate`。双方都校验来源白名单。
- 同步接口：`GET /api/v1/open/balloon-sync/{syncBatchId}` 返回冻结结果和内容摘要（SHA-256）；`GET /api/v1/open/balloon-sync?after={seq}` 列出新批次，供 QMS 轮询。
- QMS 收到通知或轮询到新批次后按批次号拉取、复算摘要，一致才进入同步收件箱；图纸页面图压缩后存进 QMS，检验页显示真实图纸和气泡。


## 原型的边界

- 扫描件 OCR 准确率有限，靠框选识别和人工校核兜底；正式版可换服务端 OCR 模型。
- 部分 CAD 软件导出的 PDF 里，形位公差符号用的是专用字体，读出来不是标准符号，需要人工选符号。
- ISO 286 只内置常用公差带（500 mm 以内），查表结果一律标“需核对”。
- 不做登录：从 QMS 打开时显示 QMS 传来的用户；数据存在服务端本地 `data/` 目录。
